# 客服审核工作台

路径：`/staff/after-sales`

## 访问与数据边界

- 只有 Django `is_staff=True` 的账号可以打开页面和调用工作台 API。
- 普通用户访问接口会收到 `403`；前端会跳回首页。
- 工单详情只展示用户与助手的文字对话，不返回 Agent 工具参数、工具结果或审计记录。

## 客服操作流程

1. 用管理员账号登录，在导航栏打开“客服工作台”。
2. 用状态、优先级、关键词筛选工单，在左侧队列选择一条记录。
3. 查看用户原因、关联订单、Agent 摘要和对话，再在右侧填写备注并更新状态。
4. 点击“保存处理结果”。系统会自动把当前登录客服设置为处理人，并写入一条人工审计记录。
5. 切换到“订单发货”页签，可查看全部订单，不依赖售后工单。对任意已支付订单点击“标记为已发货”。待支付、已取消、已发货订单不会出现发货按钮。
6. 对退款或退货退款工单，先将工单处理为“已通过”。关联订单是已支付或已发货时，可点击“标记为已退款”。订单会变为“已退款”，工单自动关闭。

## 状态流转

- 待人工审核 -> 审核中、待用户补充、已通过、已拒绝、已关闭
- 审核中 -> 待用户补充、已通过、已拒绝、已关闭
- 待用户补充 -> 审核中、已通过、已拒绝、已关闭
- 已通过或已拒绝 -> 已关闭

工单进入“已通过”“已拒绝”或“已关闭”时，会自动记录完成时间。非法流转会被 API 拒绝，不会修改原工单。
